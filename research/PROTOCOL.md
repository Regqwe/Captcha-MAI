# Протокол шести гипотез — зафиксирован до нового прогона

Предыдущие 16 просмотренных test-примеров исключаются. Первичная локальная оценка:
все оставшиеся test-изображения после проверки пересечений по декодированным пикселям.
Общее сравнение всех шести моделей: 200 случайных изображений из этого holdout,
seed 20261021, список фиксируется CSV и SHA-256 до вызовов моделей.
Это frozen-weight evaluation, обучения и подбора параметров на test нет.

1. **H1:** PP-OCRv6 tiny достаточно для 95% exact match и p95 <= 100 мс на CPU.
2. **H2:** PP-OCRv6 small улучшает exact match относительно tiny минимум на 2 п.п., p95 <= 150 мс.
3. **H3:** специализированный ddddocr beta превосходит PP-OCRv6 small по exact match.
4. **H4:** компактный предобученный Graf-J CRNN base уступает PP-OCRv6 small не более чем на 2 п.п.
5. **H5:** Graf-J Conv-Transformer base улучшает exact match относительно CRNN base минимум на 2 п.п.
6. **H6:** Gemini на общих 200 примерах уступает PP-OCRv6 small не более чем на 2 п.п.

95%, 2 п.п. и пределы задержки — предложенные инженерные критерии, а не требования
заказчика. Отдельно показываются сами измерения, чтобы можно было выбрать другие критерии.
Архитектура и обученные веса меняются вместе: H5 не является причинной ablation
чистого attention при полностью одинаковом обучении.

Первичная метрика — полное, регистрозависимое совпадение строки. CER — суммарное
расстояние Левенштейна / число символов в эталонах. Пропуски, ошибки API, отказы,
неподходящий формат считаются ошибками в знаменателе. Ведущие нули сохраняются.
Никакого исправления ответов по длине, словарю или знаниям эталона.

Для exact match — Wilson 95% CI; для разности — консервативный парный интервал
из Wilson-интервалов долей wins/losses с поправкой Бонферрони для двух долей.
Интервалы относятся к отдельным гипотезам; это исследовательский эксперимент,
не семейство подтверждённых причинных научных открытий. Для пяти парных сравнений
также вычисляются exact McNemar p и Holm-adjusted p, без удаления ошибок модели.
Гипотеза подтверждается, если интервал целиком выполняет заданный критерий;
опровергается, если целиком ему противоречит; иначе результат неопределённый.

Локально: CPU, batch=1, один непрерывный прогон, отдельная инициализация и прогрев;
время включает открытие изображения, preprocessing, inference и decoding.
У ddddocr настройки потоков библиотеки по умолчанию, у PP-OCR/HF — 2 потока.
Gemini: фиксированная фактическая модель gemini-3.8-flash, один запрос на картинку,
concurrency=4, максимум 200 первичных запросов общего test; ошибки не скрываются
повторами. Время API включает сеть и прокси, не включает ожидание в очереди пула.
Параметры запроса сохраняются без ключа и прокси-реквизитов.

Девять исходных экранов — отдельный малый target-набор. Их разметка производится
визуально ассистентом с пометками уверенности; это не независимая человеческая
экспертиза. Спорные изображения исключаются из точной target-оценки, но сохраняются.
Это development sanity check, поскольку эти изображения уже использовались раньше.

Неизвестно, пересекался ли публичный набор с обучением готовых моделей. Даже
высокий результат на нём не доказывает перенос на Instagram. Этот предел будет
явно указан в выводе. Основной результат: пригодность конкретных frozen models
на двух распределениях и обоснованное следующее решение.
