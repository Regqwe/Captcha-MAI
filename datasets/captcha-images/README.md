# Скачанный размеченный датасет

Источник: [project-sloth/captcha-images](https://huggingface.co/datasets/project-sloth/captcha-images).
Ревизия: `eeaf2b6ec9086645f270f7e2aaa9ea90730683de`. Карточка заявляет WTFPL.

В репозитории находятся **полные архивы**, а не preview: `train.tar.gz` (6000),
`validation.tar.gz` (2000), `test.tar.gz` (2000). Файлы `*_labels.csv` содержат
метки и относительные пути к изображениям; leading zeros сохранены строками.
Ответ — шестизначный префикс имени изображения в исходном архиве. Проверены
шаблоны всех имён, чтение всех файлов и соответствие шестизначному алфавиту.

`holdout_labels.csv`: 1984 test-примера после исключения 16 ранее просмотренных.
`shared_200_labels.csv`: общая случайная подвыборка для всех шести моделей,
seed 20261021. Перечень исключённых файлов — `excluded_from_holdout.csv`.
Подробные количества и SHA-256 — `audit.json`.

Распаковка без повторного скачивания:

```powershell
.\.venv\Scripts\python.exe scripts\prepare_benchmark.py
```

Изображения появятся в `data/benchmark/images/{train,validation,test}`.
В ZIP-поставке дополнительно есть отдельный готовый к просмотру test-набор.

Ведущие нули не следует открывать как числа в Excel. Python:
`pd.read_csv(path, dtype=str, keep_default_na=False)`.

Все 10 000 изображений проверены на byte/pixel duplicates; пересечений между
split не найдено. Есть 33 строки-ответа, встречающиеся в разных split с разными
изображениями. Одинаковый ответ сам по себе не является копией изображения.
Неизвестно, входил ли этот публичный корпус в обучение готовых моделей.
